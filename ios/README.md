# «Антимошенник» для iPhone

Тонкий клиент: телефон слушает разговор микрофоном и шлёт звук на сервер (`ui.server` на компьютере),
сервер распознаёт речь, ищет схему и пишет подсказки, телефон показывает то же, что веб-версия.
Устройство и API — `docs/ios/architecture.md`, требования — `docs/ios/tz-app.md`.

```
ios/
├── project.yml        # XcodeGen → Antifraud.xcodeproj (проект в Git не кладём)
├── App/               # оболочка: @main, Info.plist, иконка и AccentColor
└── AntifraudKit/      # Swift-пакет: весь код и тесты
```

## Ограничение iOS

iOS не даёт сторонним приложениям звук сотового звонка и отключает им микрофон, пока на этом iPhone
идёт звонок. Поэтому режим один: **разговор идёт на другом телефоне по громкой связи, iPhone с приложением
лежит рядом и слушает**. Реплики приходят без ролей. Если на этот iPhone позвонят во время записи,
приложение покажет «Запись прервана системой» и продолжит само, когда звонок закончится.

## Сборка

Нужны Xcode (iOS 17+) и XcodeGen (`brew install xcodegen`).

```bash
cd ios
xcodegen                      # создаёт Antifraud.xcodeproj
open Antifraud.xcodeproj
```

В Xcode: цель **Antifraud** → Signing & Capabilities → выбрать свою команду (Team). Подпись автоматическая,
bundle id — `ru.antifraud.app` (если занят — поменяйте на свой в `project.yml` и перезапустите `xcodegen`).

Сборка из терминала под симулятор (без подписи):

```bash
cd ios
xcodebuild -project Antifraud.xcodeproj -scheme Antifraud \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' \
  -derivedDataPath .build/DerivedData CODE_SIGNING_ALLOWED=NO build
xcrun simctl boot "iPhone 18 Pro"; open -a Simulator
xcrun simctl install booted .build/DerivedData/Build/Products/Debug-iphonesimulator/Antifraud.app
xcrun simctl launch booted ru.antifraud.app
```

Пакет без Xcode-проекта (на macOS, быстрее):

```bash
cd ios/AntifraudKit
swift build && swift test
```

## Сервер для телефона

На компьютере, из корня репозитория:

```bash
.venv/bin/python -m ui.server --host 0.0.0.0
```

Сервер печатает адрес в локальной сети и шестизначный код доступа (свой код — `ANTIFRAUD_TOKEN=123456`),
и объявляет себя через Bonjour (`_antifraud._tcp`). Телефон и компьютер должны быть в одной сети Wi-Fi.
Для звонка с микрофона на сервере нужны Ollama с моделями, индекс схем и распознавание речи —
приложение показывает, чего не хватает, на вкладке «Сервер».

Проверить сервер без телефона: `python -m audio.send_remote data/calls/001.wav --server http://<адрес>:8642 --token <код>`.

## Что проверить

В симуляторе (микрофон — микрофон Mac):

1. Первый запуск открывает вкладку «Сервер»: сервер находится в списке «Найденные в сети» или вводится руками
   (`127.0.0.1:8642` — симулятор ходит на этот же Mac, код не нужен).
2. «Проверить и сохранить» → «Сервер готов…» или понятная причина: не найден, не наш, нужен код, неверный код.
3. «Звонок» → тестовый звонок с сервера: идут реплики, этапы, плашки, после конца — отчёт.
4. «Слушать микрофоном»: система спрашивает доступ к микрофону, индикатор громкости двигается,
   речь у микрофона Mac появляется в расшифровке. «Стоп» → отчёт.
5. «История», «Схемы» открываются и показывают данные сервера.

На iPhone дополнительно:

1. При первом поиске система спрашивает доступ к локальной сети — разрешить.
2. Заблокировать экран во время записи — звук продолжает уходить (фоновый режим `audio`).
3. Позвонить на этот iPhone во время записи — «Запись прервана системой», после звонка запись продолжается.
4. Выключить Wi-Fi на полминуты — «Нет связи с сервером, повторяю», после включения очередь досылается.
5. Вибрация на новое предупреждение и на найденную схему; экран не гаснет, пока идёт звонок.
